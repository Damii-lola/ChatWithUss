# ChatWithUss

Order self-service & AI support widget for Shopify: order tracking, returns portal, AI FAQ, and a merchant inbox. **$15/month flat, unlimited resolutions.**

```
chatwithuss/
├── shopify.app.toml        ← app config (scopes, webhooks, app proxy). `shopify app deploy` pushes it
├── supabase/schema.sql     ← database (idempotent, safe to re-run)
├── render.yaml             ← Render blueprint for the backend
└── server/                 ← Express backend + embedded merchant dashboard (Node 20+)
    ├── src/
    │   ├── app.js                  routes wiring
    │   ├── lib/shopify/            token exchange, expiring-token refresh, Admin GraphQL client, HMAC/JWT verification
    │   ├── routes/webhooks.js      app/uninstalled, scopes_update, GDPR compliance topics
    │   ├── routes/api.js           dashboard API (session-token auth)
    │   ├── routes/proxy.js         storefront widget API (App Proxy, signed by Shopify)
    │   └── services/onboarding.js  auto-pulls shop name, logo & brand colors on install
    ├── public/                     dashboard UI (App Bridge, no build step)
    └── test/                       `npm test`
```

## Setup

### 1. Supabase
SQL Editor → paste `supabase/schema.sql` → **Run**. Safe to run again anytime.

### 2. Render
**New → Blueprint** → pick this repo (it reads `render.yaml`). Fill in the env vars it asks for:

| Variable | Where |
|---|---|
| `SHOPIFY_API_KEY` | Dev Dashboard → ChatWithUss → Settings → Client ID |
| `SHOPIFY_API_SECRET` | Same page → Secret |
| `SUPABASE_URL` | Supabase → Project Settings → API |
| `SUPABASE_SERVICE_ROLE_KEY` | Same page → `service_role` key (never the anon key) |
| `TOKEN_ENCRYPTION_KEY` | Auto-generated by the blueprint. Don't change it later |
| `CLOUDFLARE_ACCOUNT_ID` | dash.cloudflare.com → right sidebar **Account ID** |
| `CLOUDFLARE_API_TOKEN` | My Profile → API Tokens → Create Token → **Workers AI** template |

Check: `https://chatwithuss.onrender.com/healthz?deep=1` → `{"ok":true,"db":"ok"}`

**Moving to a custom domain later** (e.g. `app.chatwithuss.com`): Render → service → Settings → Custom Domains → add it, create the CNAME at your DNS provider, then replace `chatwithuss.onrender.com` in `shopify.app.toml` + `render.yaml` and run `shopify app deploy`.

### 3. Shopify config (Codespaces)
Repo → **Code → Codespaces → Create codespace on main**. The Shopify CLI installs itself (wait for the terminal to finish).

1. Open `shopify.app.toml`, replace `REPLACE_WITH_YOUR_CLIENT_ID` with your Client ID, save.
2. In the terminal: `shopify app deploy` → log in via the link it prints → answer **Yes** to release.
3. Commit the toml change: `git commit -am "Set client_id" && git push`.

### 4. Install on your dev store
Dev Dashboard → ChatWithUss → **Test on development store** → install. The dashboard opens inside Shopify admin with your store's brand already applied.

## Development

```bash
cd server
cp .env.example .env   # fill it in
npm install
npm test               # 41 tests, no network needed
npm run dev
npm run check:ai       # verifies your Cloudflare Workers AI credentials
```

AI stack: Cloudflare Workers AI. `@cf/meta/llama-3.3-70b-instruct-fp8-fast` writes the answers and `@cf/baai/bge-m3` produces the 1024-dim embeddings stored in pgvector. Both models can be swapped with `CF_AI_CHAT_MODEL` / `CF_AI_EMBED_MODEL`.

Real-database test (throwaway Supabase project only, it writes and deletes rows):
`STORE_TEST_URL=https://xyz.supabase.co STORE_TEST_KEY=<service_role> npm test`

## How auth works
- No OAuth redirects. Shopify's **managed install** + **token exchange**: the dashboard's App Bridge session token is traded for an **expiring offline token** (required for new public apps since April 2026).
- Access tokens live 1 hour and refresh automatically 5 minutes before expiry. Refresh tokens rotate and are stored AES-256-GCM encrypted.
- If credentials ever die (revoked, key rotated), the next admin visit silently re-authenticates.
- Webhooks are HMAC-verified and deduplicated by `X-Shopify-Webhook-Id`. App Proxy requests are signature-verified and rejected if older than 5 minutes.
